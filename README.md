# arisa_installer

arisa 인스톨러 입니다.

사용법은 루팅 된 기기에서
Termux에 들어가고

# 기본

```bash
pkg install git
```
을 해서 git을 설치해줍니다.
git을 설치 한 다음

```bash
pkg install wget
```
을 해서 wget도 설치해줍니다.

# 메인
```bash
git clone https://github.com/nyehuing50-wq/arisa_installer.git
```

```bash
cd arisa_installer
```

# 실행
```bash
chmod +x arisa_installer
```

```bash
./arisa_installer
```

본 Repository는 arisa 제작자 주구님의 허락을 받고 제작 한 것 입니다.

이 소프트웨어는 개인 사용 목적으로만 사용 가능합니다.
수정은 허용되나, 원본 또는 수정본의 재배포는 엄격히 금지됩니다.
